## ✂️ Engineering & Design Features

- **Fluid Mobile-First Responsive Design:** Ultra-smooth transitions tailored for high-engagement mobile browsing.
- **Comprehensive Service Menu:** Detailed price lists, estimated completion durations, and barber bios.
- **Instant Communication Triggers:** Direct WhatsApp integration for rapid booking confirmations and customer inquiries.
- **Production Asset Optimization:** Modern image pipeline with WebP formats and Next.js Image caching.

## 🚀 Quickstart

```bash
# Clone the repository
git clone https://github.com/ExeDevCentral/peluBrian.git
cd peluBrian

# Install dependencies
npm install

# Start local server
npm run dev
```
